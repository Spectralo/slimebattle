# Slime Battle

Slime battle is a Work In Progress game that I developed during HighSeas's hackclub event. The game is about multiple slimes battling against each others. (you didn't see t coming right?)

## How to play

- Clone the repository
- Run the .godot file or import the folder via Godot
_Note: You need to use Godot 4!_

## Tools used

- Aseprite
- Godot 4.3
